3D People Data Visualization

Kasatria Data Visualization is an interactive web application designed to visualize people data in a 3D environment.

The application retrieves authorized data from Google Sheets and presents the information using four interactive layouts: Table, Sphere, Double Helix, and Grid.

Users can explore information such as name, photo, age, country, interest, and net worth through an interactive 3D visualization.
